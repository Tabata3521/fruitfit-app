FruitFit web/PWA report — 14.05.2026

Готово:
1. Добавлен стабильный alias/manual mapping для сопоставления названий упражнений из программ с таблицей упражнений.
2. Matching теперь используется для подтягивания metadata/video/replacement данных без изменения исходных названий в UI программы.
3. Добавлен компонент MuscleMap и блок «Основные мышцы / Какие мышцы работают» под видео упражнения.
4. Блок мышц использует данные таблицы: мышечная группа, паттерн, целевая зона, ограничения. Для ключевых движений добавлены безопасные overrides: подтягивания/тяги, жим Арнольда, брусья, присед, планка.
5. Карта мышц подсвечивает front/back зоны SVG: primary, secondary, stabilizers. Пах/гениталии не подсвечиваются; core подсвечивается как живот/косые нейтрально.
6. Таймер подхода обновлён до режима «Работа / Отдых»: работа 30/45/60 сек, отдых 30/60/90 сек, количество подходов настраивается, есть пауза, сброс, mute и мягкие звуки.
7. Replacement logic усилена: aliases учитываются в классификации, а упражнения с конфликтом ограничений уходят в осторожные варианты. Для ограничения «спина» тяжёлые/осевые варианты дополнительно понижаются.
8. Production build успешно собран и задеплоен на Cloudflare Pages.
